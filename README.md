# 코딩테스트 풀이

프론트엔드 신입 취업을 준비하며 푼 문제들. **JavaScript** 로 풉니다 — 면접에서 말할 언어와
같아야 한다고 생각해서입니다.

문제마다 폴더를 하나 두고 `solution.js` 와 `README.md` 를 같이 둡니다.
풀이보다 **왜 그렇게 접근했는지와 시간복잡도**를 남기는 걸 목적으로 합니다.


## 기록 규칙

`README.md` 에 네 가지를 적습니다.

1. **접근** — 처음 떠올린 방법과, 그게 왜 부족했는지
2. **선택** — 최종 자료구조·알고리즘과 고른 이유
3. **복잡도** — 시간·공간, 그리고 제한 조건에서 왜 통과하는지
4. **막힌 지점** — 틀렸던 부분. 다시 보면 같은 데서 또 막힌다
